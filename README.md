# 볼트러시 GP (VOLT RUSH GP)

전기를 가득 채운 로봇들이 3바퀴를 달리는 3D 카트 레이싱 웹게임입니다.
설치 없이 `index.html` 파일 하나로 브라우저에서 바로 실행됩니다.

## 실행 방법

- **바로 실행:** `index.html`을 브라우저로 엽니다.
- **GitHub Pages:** 저장소의 Settings → Pages에서 Source를 `main` 브랜치의 `/ (root)`로 지정하면
  `https://kwonjisung.github.io/voltrush/` 주소로 열 수 있습니다.

인터넷 연결이 필요합니다. 3D 라이브러리(three.js r128)와 글꼴(Google Fonts)을 CDN에서 불러옵니다.

## 게임 규칙

- 로봇 6종 중 하나와 코스 7종 중 하나를 골라 6대가 3바퀴를 겨룹니다.
- 1위가 골인하면 30초 카운트다운이 시작되고, 그 안에 들어오지 못한 로봇은 리타이어됩니다.
- 코스와 로봇 조합마다 최고 기록이 브라우저에 저장됩니다.

## 조작법

| 동작 | 키보드 | 휴대폰 (가로 화면) |
|---|---|---|
| 가속 | ↑ / W | 자동 |
| 브레이크 | ↓ / S | 브레이크 버튼 |
| 조향 | ← → / A D | 왼쪽 핸들을 좌우로 돌리기, 또는 휴대폰 기울이기 |
| 드리프트 | Space / Shift (누른 채 꺾기) | 드리프트 버튼을 누른 채 조향 |
| 아이템 | X / Z | 아이템 버튼 |
| 일시정지 | Esc / P | 오른쪽 위 II 버튼 |

- **드리프트 부스트:** 드리프트를 유지하면 불꽃이 흰색 → 파랑 → 주황으로 차오르고, 놓는 순간 가속이 붙습니다.
- **스타트 부스트:** 출발 직전에 가속 키를 누르고 있으면 출발할 때 가속이 붙습니다.
- **기울기 조향:** https 주소(예: GitHub Pages)를 휴대폰 브라우저로 열면 기울기 센서로 조향할 수 있습니다.
  일시정지 메뉴에서 켜기/끄기, 방향 반대로, 가운데 다시 잡기를 할 수 있습니다.

## 분석 화면

메뉴 오른쪽 위의 **분석** 버튼(경기 중에는 일시정지 메뉴)을 누르면 게임이 돌아가는 원리를 그림으로 볼 수 있습니다.

- **전체 구조:** 입력 → 조작 신호 통합 → 게임 루프(물리·AI·아이템·순위·카메라) → 화면·HUD·소리·기록 저장
- **트랙 생성:** 지금 고른 코스의 제어점, 640칸 중심선, 도로·벽을 실제 좌표로 표시
- **AI 로봇:** 목표점 따라가기, 커브 감속, 아이템 사용, 실력 보정 규칙
- **드리프트·순위:** 충전 게이지와 부스트, 진행도 기반 순위, 랩 감지, 30초 리타이어, 순위별 아이템 확률

서버나 외부 AI 서비스 없이 모든 계산이 브라우저 안에서 이루어집니다.

| 코스 | 특징 |
|---|---|
| 볼트밸리 서킷 | 회로기판 위 기본 코스 |
| 용암 주조공장 | 급커브가 많은 기술형 코스 |
